About

      
    

    

      

        R Practice runs a real R session in your browser through
        webR, which is R compiled to WebAssembly. Nothing is sent
        to a server: the data frames are generated locally and your code is
        evaluated locally.
      

      

        Answers are graded on the value your code returns rather than on the text
        of the code, so base R, subset() and a dplyr pipeline are all
        accepted when they produce the same table.
      

      

        The layout and workflow follow sql-practice.com, rebuilt for R.
